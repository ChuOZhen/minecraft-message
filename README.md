# 留言板 MessageBoard

给 Minecraft Java 版 **26.3** + **Fabric** 服务器用的**离线留言**模组。
**只需要装在服务端**，玩家客户端不用装任何东西。

## 它解决什么问题

A 想找 B，但 B 不在线。A 直接留言，B 下次进服务器时就会在聊天栏看到提示，
点一下绿色的「留言」就能看到内容——不用加 QQ、不用等对方上线。

## 安装

1. 服务端装好 **Fabric Loader 0.19.5+**（Minecraft **26.3**，需要 **Java 25**）；
2. 把这两个文件丢进服务端的 `mods/` 目录：
   - `fabric-api-0.161.0+26.3.jar`
   - `msgboard-1.0.0.jar`
3. 重启服务端。看到这一行就成功了：

   ```
   [留言板] 已加载，共 0 条留言、0 个名册玩家。
   ```

## 使用

### 普通玩家

| 指令 | 作用 |
| --- | --- |
| `/msgboard send <玩家名> <内容>` | 给某位玩家留言；**玩家名按 Tab 可补全** |
| `/msgboard sent` | 查看自己发出的留言，以及对方**是否已读** |
| `/msgboard names` | 查看名称册子 |
| `/msgboard help` | 查看用法（指令可直接点击） |

例子：

```
/msgboard send Steve 明天八点一起打末影龙
```

* 对方**不在线** → 提示「已给 Steve 留言（当前有 N 条待接收），他上线时会看到提示。」
* 对方**在线** → 立刻送达。

### OP（管理员）

| 指令 | 作用 |
| --- | --- |
| `/messagename <玩家名>` | 把玩家加入**名称册子**（加入后 Tab 补全就有他了） |
| `/messagename remove <玩家名>` | 移出名称册子（**已有留言不受影响**） |
| `/messagename list` | 查看名册，并可点击 `[移除]` |

> 名称册子的用途是 **Tab 补全** 和 **提前绑定玩家 UUID**。
> 即使对方还没被登记，也照样可以给他留言——按名字记着，他上线一样能收到。

### 玩家会看到什么

进入服务器时，聊天栏出现（`[留言板]`、方括号为灰色，**「留言」为绿色**）：

```
[留言板] [Alice] 向你 留言。
```

多条留言会按发送者合并成一行：

```
[留言板] 你有 2 条新留言：[Alice] 向你 留言（2 条）、[Bob] 向你 留言。
```

**鼠标点击绿色的「留言」** → 立刻显示内容：

```
[留言板] 来自 Alice 的留言（2026-10-05 13:40）： （已标记为已读）
明天八点一起打末影龙
```

### 已读回执

对方点开看过之后，发送者执行 `/msgboard sent` 会看到：

```
 #3 → Steve 2026-10-05 13:40 [已读 2026-10-05 14:02]
 明天八点一起打末影龙
```

状态有三种：`[已读 <时间>]`（绿）、`[已送达未读]`（黄）、`[未送达]`（灰）。

## 数据与备份

所有留言与名册都存在**世界存档目录**下的一个文件里：

```
<服务端目录>/<世界名>/msgboard.json
```

* 想备份 → 复制这个文件；
* 想清空全部留言和名册 → 停服后删掉它；
* 写入采用「临时文件 + 原子替换」，服务器意外崩溃不会写坏存档；
* 如果不小心把文件改坏了，服务器**仍能正常启动**，坏文件会被改名成 `msgboard.json.bak`。

## 从源码构建

需要 **JDK 25**。

```powershell
.\gradlew.bat build
# 产物：build/libs/msgboard-1.0.0.jar
```

## 设计说明（给开发者）

* 主指令刻意用 `/msgboard`，**不覆盖**原版 `/message`、`/msg`、`/tell`、`/w` 私聊；
* 26.3 起 Minecraft 源码不再混淆，Fabric 已弃用 Yarn，本项目用 **Mojang 官方名**，
  `build.gradle` 里**没有** `mappings` 行；
* 点击行为用 `ClickEvent.RunCommand` 直接执行 `/msgboard read <ID>`，
  不会把指令填进输入框，不存在误发到公屏或指令注入的问题；
* 留言正文进客户端前会去颜色符号、压成单行；
* `read` 有归属校验，点别人的留言链接会被拒绝。

详细实施规格见 [deepseek.md](deepseek.md)。
